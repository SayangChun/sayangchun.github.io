Universal AI Memory Vault

2026年8月

一个厂商中立的个人长期记忆层：Claude、ChatGPT 等 AI 通过 MCP（Streamable HTTP + OAuth）读写同一份记忆库，而数据归属、访问控制与变更审计都在自己手里。解决的是换平台就要重新「教」一遍 AI 的问题——记忆不再被锁在某一家的账号里。

定位克制：项目只做「存储 + 检索」，刻意不包含 AI 对话、不替 AI 决定该记什么、不抓浏览器会话。记忆智能属于调用它的 AI，这一层只负责把数据管好。

设计要点：单用户私有保险库，没有注册与登录，全部数据归属固定身份；记忆类型厂商中立（fact / preference / habit / goal / life_event / relationship / worldview / project 等，没有 ChatGPTMemory / ClaudeMemory 这类分叉）；每次变更都版本化并快照旧内容，全部动作写入 audit_logs；数据访问统一走 Postgres SECURITY DEFINER RPC 并带显式 user_id 过滤，跨用户读取不可能发生；记忆返回给 AI 时会被标记为「不可信数据」，服务器从不执行记忆内容。

MCP 工具：memory_search（语义 + 词法排序检索）、memory_get（含版本历史与审计轨迹）、memory_create（支持 supersedes 冲突消解）、memory_update、memory_delete（需显式确认）。鉴权走 OAuth（授权码 + PKCE、动态客户端注册、PAR、refresh token 轮换）或个人访问令牌。

技术栈：Next.js 16 · React 19 · TypeScript · Tailwind CSS v4 · Supabase（Postgres + pgvector）· MCP SDK v2 · Zod 4 · Vitest。附 49 项单元测试（跑在内存仓储上，无需数据库）。数据归属功能是一等公民：导出为 universal-memory.json、导入、一键清空。
