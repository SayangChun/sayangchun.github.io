天之川沙夜 · 桌面陪伴

2026年7月

以《仰望夜空的星辰》角色天之川沙夜为形象的 Windows 桌面陪伴应用：VPet 风格全身桌宠，默认以全身立绘常驻桌面，可拖动、托盘驻留，支持点击互动、聊天与夸奖，并带基础星轨亲密度（0–100 与对应称谓）。

全身动态：以姿势帧序列切换实现动作（类似 VPet 精灵帧动画），脚底为锚点并带轻微 CSS 补间——待机呼吸、左右张望、原地小跑；坐下 / 蹲 / 侧躺 / 趴等低位休息；伸懒腰、挥手、弹跳、害羞、庆祝、被拎起；以及沉思、探头、哈欠、轻笑、问候等组合动作。固定冬制服形象，帧资源在 assets/animations/<动作>/，可用 build_animations.py / build_rest_poses.py 重新打包。

行为与分区：behaviors.js 支持一个行为配置多条加权动作链（链内顺序播放、中间不回 idle）；贴边 / 角落 idle 更安静，开阔区 freer（屏幕分区姿势可关）。漫游规划支持垂直爬升 / 下降路径，并统一各姿势高度、降低漫游频率、拉长休息停留，让节奏更自然；沙夜还能记住你的称呼并在对话中叫出来。

交互与窗口：拖动移动（拖动时被拎起姿势）；单击对话 / 弹跳；快捷栏（聊聊 / 夸奖 / 散步 / 小跳 / 坐下 / 漫游 / 星轨 / 隐藏等）由脚底 Dock 演进为左右侧栏；系统级点击穿透与动态窗口缩放；Esc 先收栏 / 气泡再隐藏到托盘。定位为纯陪伴，不含效率工具。

技术栈：Electron（v0.4.0）；本地运行 npm install 后 npm start。角色版权归属原作相关权利方，个人向原型，勿作商业用途。
