sp500-cn-comparison · 境内标普500标的穿透对比

2026年9月

把中国境内跟踪标普500的 10 只标的拉到同一张表上比：从基金中期报告穿透出「真实参与率 / 加权综合费率 / 场内溢价」，再做五维加权打分。方法论来自 B 站 @林怀瑾LHJ 拆解纳指100场外基金业绩差异的那套方法，本项目把它映射到标普500。

为什么要穿透：同一指数、同一区间、同一币种，场外产品的半年净值增长率最多差 1.35 个百分点，三年差到 10.9 个百分点。差异不来自「选股」，而来自三件被披露口径藏起来的事——净值里有多少钱真的买了指数（参与率）、页面上写的费率是不是实收（加权综合费率）、场内买入要多付多少溢价。

几个结论：场外产品没有一只做到 100% 参与指数（穿透后 94.03%–95.19%，差额停在现金和应收款里，牛市里就是少赚的钱）；费率与收益几乎是两件事（Spearman 秩相关仅 0.30）——博时 ETF 费率只排第 6 但三年收益排第 1，摩根 A 费率全场最低而收益只排第 7。

2026-10-25 滚动更新（数据基准日 2026-10-22）：三季报要到 10-31 才披露，所以参与率 / 费率 / 规模仍是中报口径，多期收益、场内溢价与申购状态已滚动到最新交易日。三件事变了——①场内溢价大幅扩大：四只 QDII ETF 从一年前的 1.90%–5.27% 涨到 6.83%–8.15%，溢价调整后的有效参与率从 96%+ 降到 92.3%–93.5%；同期国泰 ETF（159612）暂停申购，新份额停止创设，这正是它溢价走高的直接原因。②座次换了：博时 ETF 反超登顶（89.70），华夏 ETF 从第 1 掉到第 4（91.04 → 74.14），因为近一年 7.43% 在四只 ETF 里垫底。③国泰联接从第 10 跳到第 6，但它在 1–8 名之间跳，靠的是近一年 10.08% 这一个窗口，近三年 60.10% 只排第 6——不建议据此重仓。

量化排名（五维加权，满分 100）：权重为长期收益兑现 40 / 真实敞口 20 / 持有成本 20 / 规模与稳定 12 / 买入摩擦 8。前四名仍是场内 ETF——博时 89.70、南方 87.73、国泰 81.54、华夏 74.14，与场外（最高 58.09）之间仍有明显断层，断层主要来自「真实敞口」和「持有成本」两项。另做了多组替代权重与窗口的稳健性检验，标出名次会在区间内浮动的产品。

工程与交付：纯 Python 流水线（下载定期报告 → 解析 PDF → 抓行情与份额净值 → 穿透计算 → 打分 → 生成图表 → 生成站点）。图表用手写 SVG 生成，不依赖 matplotlib 与中文字体，体积只有几十 KB、任何缩放下都清晰，能被 GitHub 直接内嵌渲染。另附一个备用推送工具，在 git push 被网络代理阻断时改走 GitHub API 提交。

已做的交叉验证：中报 3.2.1 披露的「过去六个月份额净值增长率」与独立拉取的日净值复算结果逐只核对一致（含分红调整）；场内收盘价用东方财富与腾讯行情两个源逐点核对；期末净资产均满足勾稽关系。

局限也写在明面上：业绩比较基准口径不统一（同样标普500，博时写 NTR 得 6.60%、国泰/南方只有 6.16%），参与率只有期末一个时点，联接基金跑赢自家目标 ETF 的现象未解释，QDII 溢价率存在 T+1 披露时滞的口径陷阱。
