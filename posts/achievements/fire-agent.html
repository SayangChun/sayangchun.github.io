FIRE-Agent · 可移植的 AI 财务顾问

2026年9月

一个可移植的 AI FIRE 数字员工：把 FIRE 顾问能力打包成一套知识包，直接运行在你自己已有的 AI 平台上（ChatGPT / Gemini / Claude），不需要 API Key、不需要服务器、不需要额外订阅。

核心理念：Agent Core ≠ AI Runtime。指令、方法论、计算公式、风险框架与数据 Schema 与运行平台解耦，换平台只需要换一份 adapter 说明；数据留在自己的会话与文件里，不做外部存储。

能力覆盖：FIRE 数值（年支出 ÷ 提取率）、FIRE 进度（当前资产 ÷ FIRE 数值）、储蓄率对时间线的影响、FIRE 年龄复利模拟、保守 / 基准 / 乐观三档情景、10,000 次蒙特卡洛成功概率、Lean / Regular / Coast / Barista / Fat 等 FIRE 类型、序列风险 / 通胀 / 长寿 / 集中度等风险分析、策略取舍的定量对比，以及「45 岁退休需要什么」的逆向规划。

工程取向：确定性数学交给代码算，而不是让 LLM 估；core/ 存放指令、方法论、公式、风险框架、Schema 与 5 个示例案例，adapters/ 提供四个平台的接入指南，tools/ 为 Python 计算器，templates/ 给出财务画像模板，并附 86 项单元测试。

使用方式：选平台 adapter → 建 AI Agent → 上传 core/instructions.md → 上传方法论 / 计算公式 / 风险知识 → 上传填好的财务画像 → 直接对话「帮我分析我的 FIRE 进度」。
